# Legacy Console Edition+

neoLegacy (Windows) with Java Edition commands and command blocks.

## Download

Get the zip from the [latest release](https://github.com/Volistic/legacy-console-edition-plus/releases/latest).

## Install

1. Unzip it into its own folder.
2. Run `Minecraft.Client.exe`.

On Linux, run it with Wine or Proton (Proton-GE works best).

Back up your worlds before opening them in a modded version.

## What it adds

- Command blocks: impulse, repeating and chain, plus craftable survival command blocks that cost XP levels
- Java Edition commands from 1.12 to 26.3, chosen per world, with Java-style autocomplete in chat and the command block editor (keyboard and controller)
- Titles, action bar, boss bars, scoreboard sidebar and `/dialog`
- Data packs and `.mcfunction` files (`/reload`, `/function`)
- Newer attributes (`scale`, `gravity`, `step_height`...), game rules and `/tick`
- Marker, interaction and display entities (1.20.4 and 26.3 command versions)
- An in-game command wiki: How to Play > Commands

See each release's notes for what changed.
